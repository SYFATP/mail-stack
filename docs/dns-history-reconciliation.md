# DNS 历史任务核对

DNS 写入发生超时、回读异常或服务中断时，任务可能标记为 `unknown`（待核对）。该状态表示外部写入结果需要确认，系统不会自动重放写入或领取。

完成 DNS 验证、DNS 应用或 dynv6 自动完成任务后，系统会尝试核对同域名的旧 `dns_apply` 任务：

- 使用当前配置版本的新鲜成功 DNS 检查；任务 `succeeded` 本身不足以证明检查通过。
- 只读获取当前 provider 的记录，检查凭据、Zone、目标内容和唯一性；活动的父子域名任务会阻止本次核对。
- 仅当原任务的全部操作都有明确记录证据时更新状态。读取失败、缺失或冲突记录、变更的凭据和不确定 record ID 继续保留待核对。
- 核对完成的原任务记为 `partial / dns_history_reconciled`，保留原始错误、完成步骤和已确认的记录 ID，并追加核对时间、验证任务 ID 和当前记录 hash。
- 核对只确认当前状态，不冒领记录 ownership，也不把中途停止的原任务标为全部成功。`claim` 和其他未知写任务保持原有处理规则。

没有待核对历史的域名不会因这项功能增加 provider 读取。原任务保留在任务记录中，已完成核对的记录不再计入顶部“待核对”数量。
